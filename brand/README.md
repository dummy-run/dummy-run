# Brand

Nothing final lives here yet. Direction, from the naming research (docs/NAMING.md):

- Wordmark: "Dummy Run", two words in prose, `dummyrun` as the command and package name.
- Mascot: an original crash-test dummy, friendly, drawn from scratch. Do not reference "Vince and Larry"
  (a live US registered mark owned by NHTSA), do not trace photographs of Hybrid III dummies, and do not use
  the phrase "Crash Test Dummies" (a band).
- Working colours until a palette is designed: amber `#fbad18`, ink `#1d1d1b`, pass `#15803d`, blocker `#9c1924`.
- Type: sizes per docs/TYPOGRAPHY.md; typeface open.
