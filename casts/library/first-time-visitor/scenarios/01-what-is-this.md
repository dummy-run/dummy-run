# Say what this is in ten seconds

Device: desktop. Start at the home page.

## Given

Alex has just landed from a link with no explanation.

## Goal

"Say in one sentence what [the product] is and who it is for, using only the first screen."

## Steps Alex would take

1. Read the first screen without scrolling.
2. Write down what Alex thinks it is.
3. Scroll once if the first screen was not enough.
4. Compare the guess with what the page says it is. Finish.

## Success looks like

- Alex could say what it is and who it is for from the first screen.
- No unexplained word stood between Alex and the answer.

## What to report

Alex's one-sentence guess. Words that were unclear, with step numbers.
