# Find the first step

Device: desktop. Start at the home page.

## Given

Alex is ready to try it. The final submit is blocked, so Alex stops at any form.

## Goal

"Find the single clearest way to start and say what it asks of Alex."

## Steps Alex would take

1. Look for a button such as Start, Sign up or Try.
2. Follow it and read what it asks for.
3. Count the fields or steps shown. Do not submit.
4. Say whether Alex would carry on and why. Finish.

## Success looks like

- There was one clear way to start.
- Alex knew what it would ask for before committing.

## What to report

The button Alex chose and why. What was asked. Any competing buttons that made the choice hard.
