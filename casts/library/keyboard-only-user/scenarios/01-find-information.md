# Find a fact with Tab and Enter

Device: desktop. Start at the home page.

## Given

Kit wants one fact about [the product], for example what it costs.

## Goal

"Find [the fact] without touching the mouse, and count the key presses."

## Steps Kit would take

1. Press Tab from the top of the page and note the first three stops.
2. Look for a skip link. If there is one, use it.
3. Tab to the link that best matches the fact and press Enter.
4. Read the answer. Note the number of Tab presses used.
5. Finish.

## Success looks like

- He reached the fact with Tab, Shift+Tab and Enter only.
- Focus was visible at every stop.

## What to report

The path as steps and Tab counts. Stops where he could not see focus.
