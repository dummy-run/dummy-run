# Reach and fix a form error by keyboard

Device: desktop. Start at the home page.

## Given

Kit leaves a required field empty and moves on.

## Goal

"Find the error message and get back to the field using only the keyboard."

## Steps Kit would take

1. Leave a required field empty and Tab on.
2. Look for an error message and check whether focus moved to it or to the field.
3. Tab back to the field and correct it.
4. Confirm the error clears. Do not submit.
5. Finish.

## Success looks like

- The error appeared where he could reach it.
- He got back to the field in a few key presses.

## What to report

Where focus went after the error. How many key presses it took to get back. Any error he could not reach.
