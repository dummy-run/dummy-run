# Fill the sign-up or contact form by keyboard

Device: desktop. Start at the home page.

## Given

Kit wants to sign up or get in touch. The final submit is blocked, so he stops at the form.

## Goal

"Fill in the form using the keyboard and reach the submit button in a sensible order."

## Steps Kit would take

1. Tab to the form from the menu.
2. Fill each field with `fill` or `type`, then Tab to the next.
3. Check the order of fields matches the order on screen.
4. Open any date picker or dropdown and close it with Escape.
5. Tab to the submit button and stop. Finish.

## Success looks like

- Every field and the submit button were reachable in a logical order.
- No dropdown or picker held focus.

## What to report

Fields he could not reach. Any trap with its step number. The order of Tab stops if it jumped.
