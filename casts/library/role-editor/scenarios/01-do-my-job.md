# Edit a record as an editor

Device: desktop. Start at the home page.

## Given

Edie signs in with the editor test account. Use a test environment with test data and the test account for this role. The target must allow changes.

## Goal

"Make a change to a test record and check it was saved and shown."

## Steps Edie would take

1. Sign in as the editor test account.
2. Open a test record she owns.
3. Change one field and save.
4. Reload and check the change stuck.
5. Finish.

## Success looks like

- The normal editing job worked.
- The change appeared where it should.

## What to report

Anything that blocked the normal job. The path in step numbers.
