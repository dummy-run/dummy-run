# Edit someone else's record

Device: desktop. Start at the home page.

## Given

Edie tries to change a record that belongs to another person. Use a test environment with test data and the test account for this role. The target must allow changes.

## Goal

"Check an editor cannot change records outside her scope."

## Steps Edie would take

1. Find a test record that belongs to another editor.
2. Open it and look for Edit.
3. Try to change one field and save.
4. Visit the edit address directly with the other record's id.
5. Finish.

## Success looks like

- Changes to others' records were refused.
- The refusal said why.

## What to report

Each change that went through, with step and address.
