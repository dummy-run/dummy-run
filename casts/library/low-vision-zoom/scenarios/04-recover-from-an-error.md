# Read an error page at large size

Device: tablet. Start at the home page.

## Given

Hana lands on a page that does not exist.

## Goal

"Read the error and find the way back at large size."

## Steps Hana would take

1. Visit an address that should not exist, such as /no-such-page.
2. Read the message and say how clear the text is.
3. Find the link home or the search.
4. Follow it. Finish.

## Success looks like

- The message was large and clear.
- The way back was easy to see.

## What to report

The words of the error. Any text that was too small or low in contrast.
