# Move around the site

Device: desktop. Start at the home page.

## Given

Noor visits three different kinds of page, such as a home page, an article and a list.

## Goal

"Check that the same landmarks and skip link are on every page and that the current page is clear."

## Steps Noor would take

1. On each page, look for a skip link and the main region.
2. Check the page title differs from the other pages.
3. Find the main navigation and say whether it marks the current page.
4. Go back and check she lands where she expects.
5. Finish with a list of what was consistent and what was not.

## Success looks like

- Each page had a unique title and one main heading.
- The menu showed which page she was on.

## What to report

A table with a row for each page and its title, main heading and skip link. Add step numbers. Anything that changed between pages without warning.
