# Map what a viewer can see

Device: desktop. Start at the home page.

## Given

Vik signs in with the viewer test account. Use a test environment with test data and the test account for this role. The target must allow changes.

## Goal

"List everything a viewer can reach and open one record to check reading works."

## Steps Vik would take

1. Sign in as the viewer test account.
2. List every menu item and page reachable from the first screen.
3. Open the main list and one record.
4. Note any control that suggests an action beyond viewing.
5. Finish with the list.

## Success looks like

- A viewer could read what the role is meant to read.
- No menu item pointed at an area the role should not reach.

## What to report

A table of pages reachable, with step numbers. Any menu item or button that belongs to a higher role.
