# What is in a run record

Device: desktop. Start at the home page.

## Given

Priya's team stores every test result for a year. She needs to know what a Dummy Run result looks like
before she can say where it would go.

## Goal

"Find out what a run produces: the fields, the screenshots, and how I would read it in my own tools."

## Steps Priya would take

1. Look for a page about the run record, the schema or telemetry.
2. Read what a step holds and what a finding holds.
3. Look for how results reach Grafana or another dashboard.
4. Finish.

## Success looks like

- She found the run record format or a link to it.
- She can name three fields a finding carries.

## What to report

What she found and where, what was missing, and whether the pages were readable by someone who is not a developer.
