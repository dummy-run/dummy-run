# Find the quickstart

Device: desktop. Start at the home page.

## Given

Tom's build takes four minutes. He wants a command to paste.

## Goal

"Find the fastest way to run Dummy Run against my pull-request preview, or find out that it is not ready yet."

## Steps Tom would take

1. Scan the home page for Get started, Quickstart, Install or a code block.
2. Follow the most promising link.
3. If there is a command, read what it needs. A binary or a browser. A model provider or an account.
4. If there is no command after two pages, note where he gave up.
5. Finish.

## Success looks like

- He found an install or run command, or a clear statement that nothing installs yet.
- He can list what he would need before the first run.

## What to report

The path he took as step numbers. Whether the pre-release state is stated plainly. Any link that did not do
what it said.
