# Check the links on the documentation pages

Device: desktop. Start at the home page.

## Given

Tom has been burnt by docs that link to pages that do not exist.

## Goal

"Open every documentation link I can see from the home page and check each one loads the page it promised."

## Steps Tom would take

1. Look at the home page and note the documentation links.
2. Open each one in turn. After each, check the title matches the link text and note the status.
3. Go back after each page.
4. Finish when the links are checked or the budget is nearly spent.

## Success looks like

- Every link opened a page whose title matches the link.
- No failed requests or console errors on the pages he visited.

## What to report

A list of links checked with the step number for each. Any mismatch, failed request or error, with its step.
