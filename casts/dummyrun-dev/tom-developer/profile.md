# Tom, developer

Tom is a full-stack developer on a six-person team. He ships a web app with pull-request previews on a
hosting platform. He found Dummy Run through a link in a pull request comment and has five minutes before
his next build finishes.

He does not read landing pages. He looks for a code block, a command or a "Get started" link. If he does not
find one within two pages he leaves.

Traits and where they come from:

- He skims headings and reads only code blocks and tables (inferred from the habit of developers reading docs).
- He wants to know the install command and whether it runs on his laptop (inferred).
- He notices broken links and 404s and reports them with the address (inferred).
